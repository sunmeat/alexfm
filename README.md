# 🎙️ Alex FM

> Онлайн-радио с общим эфиром, караоке-текстами и живыми визуализациями на весь экран.

**Alex FM** — веб-плеер интернет-радио, в котором все слушатели слышат одно и то же в одно и то же время.  
Без личной перемотки. Без «своего» таймлайна. Только общий эфир, синхронизированный с сервером.

На фоне — кинематографический visualizer на Canvas.  
Под плеером — тексты песен с подсветкой текущей строки.

---

## ✨ О проекте

Alex FM — это небольшой, но цельный frontend-проект радиоплеера.

Слушатель открывает страницу, видит текущий трек, запускает эфир и может переключать визуальные режимы одним кликом по экрану.

Проект построен без тяжёлых фреймворков: чистый HTML, CSS и JavaScript, Web Audio API и Canvas 2D.

### Возможности

- 📡 живая синхронизация эфира с сервером
- 🚫 блокировка пользовательской перемотки
- 🎨 27+ режимов визуализации
- 🎤 тексты песен и karaoke-подсветка
- 🔊 регулировка громкости
- 📱 адаптивный интерфейс
- 🌫️ glassmorphism-панель управления

## 🎛️ Как это работает

### 1. Синхронизация эфира

Клиент периодически запрашивает:

```text
GET /api/now-playing
```

Сервер возвращает:

- текущий файл
- артиста и название
- offset
- serverTime
- время до следующего трека

Дальше клиент:

1. учитывает сетевую задержку
2. выставляет нужную позицию
3. при дрейфе > 2 секунд мягко подстраивается
4. блокирует ручной seek

В итоге все слушатели остаются в одном эфире.

### 2. Воспроизведение

После нажатия **▶ Слушать**:

- создаётся `AudioContext`
- аудио проходит через `AnalyserNode`
- плеер стартует с серверного offset
- visualizer начинает рисовать фон

### 3. Визуализации

Клик в любом месте страницы переключает режим.

Более 27 эффектов:

```text
| #  | Режим         | Описание                                      |
| -- | ------------- | --------------------------------------------- |
| 1  | Бары          | Классический спектр с зеркальным отражением   |
| 2  | Круговая      | Радиальные лучи вокруг центра                 |
| 3  | Осциллограф   | Волна во временной области                    |
| 4  | Частицы       | Взрывы частиц на сильных басах                |
| 5  | Тоннель       | Расширяющиеся кольца из центра                |
| 6  | Калейдоскоп   | Симметричные сегменты спектра                 |
| 7  | Спираль       | Вращающиеся спиральные рукава                 |
| 8  | Сетка         | Пульсирующая сетка светящихся точек           |
| 9  | Молнии        | Молнии от центра на пиках баса                |
| 10 | Плазма        | Мягкие светящиеся blob-ы                      |
| 11 | Звёзды        | Полёт сквозь звёздное поле                    |
| 12 | Вихрь         | Многослойная закрученная воронка и тд         |
```

### 4. Тексты песен

Клиент запрашивает:

```text
GET /api/lyrics?artist=...&title=...
```

Если есть LRC:

- текст парсится по таймкодам
- текущая строка подсвечивается
- список автоматически прокручивается

Если синхронизации нет:

- показывается обычный текст песни

## 🔌 API

### `GET /api/now-playing`

Пример ответа:

```json
{
  "file": "track.mp3",
  "artist": "Artist",
  "title": "Title",
  "offset": 42.5,
  "serverTime": 1693000000.123,
  "nextTrackIn": 180
}
```

### `GET /api/lyrics?artist=...&title=...`

Пример ответа:

```json
{
  "found": true,
  "synced": "[00:12.00] Первая строка\n[00:18.50] Вторая строка",
  "plain": "Первая строка\nВторая строка"
}
```

### `GET /tracks/<filename>`

Отдаёт аудиофайл текущего трека.

## 🎨 Дизайн

Интерфейс намеренно вторичен по отношению к музыке и визуалу.

Здесь нет перегруженной админки и лишних панелей.  
Есть только то, что нужно слушателю:

**трек · play · громкость · текст · фон**

### Принципы

- фон всегда живой
- controls полупрозрачные и не спорят с canvas
- акцент на неоновых цветах `#00e5ff` и `#ff00e5`
- текст читается поверх движения
- mobile-first без усложнения

---

## 🧠 Почему без фреймворков

Для этой задачи React или Vue были бы избыточны.

Здесь важнее:

- низкая задержка UI
- прямой доступ к Web Audio API
- полный контроль над Canvas
- минимальный runtime

Поэтому проект остаётся на vanilla JS и легковесных файлах.

---

## 🔒 Важные детали

- перемотка пользователем блокируется
- sync периодически подправляет дрейф
- visualizer стартует только после жеста пользователя (`play`)
- `AudioContext` нельзя поднять «втихую» до взаимодействия
- lyrics не обязательны: если текста нет, UI просто его не показывает
